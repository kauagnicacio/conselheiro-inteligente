# 📚 Material Bônus - Estrutura de Arquivos

Esta pasta contém os materiais bônus disponíveis na aba "Meu Material" do aplicativo.

## 📂 Estrutura de Pastas

```
public/bonus/
├── ebooks/          ← PDFs dos ebooks
└── audios/          ← MP3s dos áudios guiados
```

## 📖 Ebooks (PDFs)

Adicione os seguintes arquivos PDF na pasta `ebooks/`:

- `ebook-01-chat.pdf` - Chat com a Lum
- `ebook-02-100-perguntas.pdf` - 100 Perguntas para si mesmo
- `ebook-03-minha-jornada.pdf` - Minha Jornada
- `ebook-04-7-emocoes.pdf` - As 7 Emoções

## 🎧 Áudios Guiados (MP3)

Adicione os seguintes arquivos MP3 na pasta `audios/`:

- `01-acalmar-agora.mp3`
- `02-mente-acelerada.mp3`
- `03-antes-de-dormir.mp3`
- `04-acordei-ansioso.mp3`
- `05-quando-estiver-triste.mp3`
- `06-raiva-limite.mp3`
- `07-autocobranca.mp3`
- `08-culpa-reparo-ou-perdao.mp3`
- `09-vergonha-acolhimento.mp3`
- `10-confusao-clareza.mp3`

## ⚠️ Importante

- **Nomenclatura exata**: Os nomes dos arquivos devem ser EXATAMENTE como listado acima
- **Formatos**: PDFs para ebooks, MP3 para áudios
- **Localização**: Arquivos devem estar nas pastas corretas (ebooks/ ou audios/)

## 🚀 Como Testar

1. Adicione os arquivos nas pastas corretas
2. Acesse o app em /home
3. Clique no menu lateral > "Meu Material"
4. Teste abrir PDFs e reproduzir áudios

## 📱 Funcionalidades

- **Ebooks**: Clique em "Abrir PDF" para visualizar em nova aba
- **Áudios**: Clique no botão Play para reproduzir
- **Player**: Controle de play/pause com mini-player fixo
- **Paywall**: Em /teste (modo demo), qualquer clique abre popup de checkout
