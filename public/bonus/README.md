# Estrutura de Arquivos Bônus

Esta pasta contém os materiais exclusivos (ebooks e áudios guiados) da Lum IA.

## Estrutura de Pastas

```
public/bonus/
├── ebooks/          # PDFs dos ebooks
└── audios/          # MP3 dos áudios guiados
```

## Ebooks (PDF)

Adicione os seguintes arquivos em `public/bonus/ebooks/`:

- `ebook-01-chat.pdf` - Chat com a Lum
- `ebook-02-100-perguntas.pdf` - 100 Perguntas para si mesmo
- `ebook-03-minha-jornada.pdf` - Minha Jornada
- `ebook-04-7-emocoes.pdf` - As 7 Emoções

## Áudios Guiados (MP3)

Adicione os seguintes arquivos em `public/bonus/audios/`:

- `01-acalmar-agora.mp3` - Acalmar Agora
- `02-mente-acelerada.mp3` - Mente Acelerada
- `03-antes-de-dormir.mp3` - Antes de Dormir
- `04-acordei-ansioso.mp3` - Acordei Ansioso
- `05-quando-estiver-triste.mp3` - Quando Estiver Triste
- `06-raiva-limite.mp3` - Raiva & Limite
- `07-autocobranca.mp3` - Autocobrança
- `08-culpa-reparo-ou-perdao.mp3` - Culpa: Reparo ou Perdão
- `09-vergonha-acolhimento.mp3` - Vergonha & Acolhimento
- `10-confusao-clareza.mp3` - Confusão & Clareza

## Notas Importantes

- **Formato dos Ebooks**: PDF
- **Formato dos Áudios**: MP3
- **Nomenclatura**: Mantenha exatamente os nomes dos arquivos como especificado acima
- **Localização**: Os arquivos devem estar nas pastas corretas para funcionar no app

## Funcionamento no App

- **Em /home**: Usuários autenticados podem abrir ebooks e tocar áudios normalmente
- **Em /teste**: Qualquer clique em ebook/áudio abre o popup de checkout (modo demo)
